# これまでの経緯

claude.ai での対話（2026年9月〜10月）で作ってきた内容のまとめです。

## 1. 最初のモデル（楕円体の組み合わせ）
- 楕円体を組み合わせたデフォルメ寄りのモデルを GLB で作成
- 参照写真（`reference/guinea-pig-photo.jpg`）の三毛模様をテクスチャで再現し、ボーン 10 本とスキンウェイトを追加

## 2. ゲームエンジンの選定 → Babylon.js
- 「Web で動くゲームエンジン」として、Babylon.js / Three.js / PlayCanvas / Unity・Godot の Web 書き出しを比較
- 小規模チーム（2 人）でコードを書く前提なら、物理・アニメーション・GUI・インスペクターが最初から揃う **Babylon.js** を推奨し、採用
- Three.js は自由度が高いが、ゲームの仕組みを自前で組む部分が多い。Unity/Godot の Web 書き出しは重く、スマホのブラウザでは起動が遅い

## 3. リアル寄りのモデルへ作り直し
- 楕円体の寄せ集めではデフォルメの域を出ないため、SDF（符号付き距離関数）で頭・頬・口元・胴・お尻をなめらかに融合し、マーチングキューブで**1 枚の連続メッシュ**にした
- 毛並みは Babylon 側のシェルファーで表現（GLB には毛が入っていない）
- 模様はテクスチャをやめて頂点カラーに（UV 展開が不要なため）
- ボーンに `nose` を追加して 11 本に
- ヘッドレスブラウザでスクリーンショットを撮りながら、毛の密度・顔の模様・耳の向き（垂れ耳）・胴の長さを数回調整

## 4. 待機と歩行
- キーフレームではなく手続き的アニメーションで実装。待機と歩行を「歩いている度合い」で混ぜて、切り替えても途切れないようにした
- 歩行は対角の足が同時に出るトロット風。旋回時はその場で足踏み

## 5. 鳴き声
- 録音素材は使わず Web Audio で合成（ライセンスの心配がなく、毎回少しずつ違う声になる）
- ウィーク / グルグル / クックッ の 3 種類。鳴き声のイベント列でアニメーションも動かす
- 本体のタップで「なでる」操作を追加

## 6. Claude Code への引き継ぎ（このリポジトリ）
- claude.ai 上の 1 ファイル版（GLB を base64 で埋め込んだ HTML）を、Vite のプロジェクトに分割
- モデル生成スクリプトを同梱し、同じ GLB がバイト単位で再現できることを確認
- 検証スクリプト（GLB 検証、スモークテスト、WAV 書き出し）を追加
